# تحديث الهندسية المتحدة

الهوية واللوجو باسم **الهندسية المتحدة**، والمركز في **الحدايق**. كل طلب جديد يتسجل للمركز نفسه، من غير اختيار فروع وهمية.

## المدير

الصفحة الرئيسية تفتح إنشاء الطلبات، الموافقات، المخزون، التقارير وإدارة الموظفين. شريط التنقل يفتح الطلبات والعملاء والفنيين. من أي طلب يمكن مراجعة بيانات العميل والجهاز والموعد والفني والفحص وقطع الغيار والصور وسجل العمل والفاتورة وتوقيع العميل. يمكن تعديل وصف العطل والأولوية، وتحديد الفني أو تغيير موعده عندما تسمح حالة الطلب.

ملف الفني يعرض زيارات اليوم أو أي يوم تختاره، وعناوين الزيارات وحالة التنفيذ وسجل طلباته. **خط السير جدول زيارات وسجل تنفيذ، ولا يتضمن تتبع GPS مباشرًا.**

الفواتير الصادرة تُعرض بالقيم المحفوظة وقت التسليم وتُشارك PDF. تعديل بيانات العميل لاحقًا لا يغير عنوان الزيارة المحفوظ في طلب سابق.

## الفني

بدء الزيارة إجراء واضح. قطع الغيار المستخدمة تتسجل من المخزون بسعرها الفعلي، والكمية تتخصم مرة واحدة. يجب إنهاء الفحص وتسوية القطع المطلوبة قبل تسليم الطلب.

المصنعية والخصم يدخلهم الموظف بدل المبلغ الثابت. التوقيع يسمح بخطوط منفصلة ولا يوصلها ببعض؛ المسودة تبقى عند فشل الحفظ. الصورة والمبالغ واسم المستلم تُحفظ عند نجاح التسليم، ويمكن فتح الفاتورة لاحقًا.

## بدء التشغيل والبيانات

على قاعدة جديدة: `npm ci` ثم `npm run migrate` ثم إعداد حساب المدير الحقيقي عبر متغيرات `MANAGER_*` وتشغيل `npm run bootstrap`. بعدها أضف الموظفين والمخزون من التطبيق. لا يضيف بدء التشغيل عملاء أو طلبات أو فواتير تجريبية، ولا يوجد رابط HTTP لمسح البيانات وإعادة زرعها.

**التحديث لا يحذف بيانات السيرفر الحالي.** لو فيه بيانات قديمة تجريبية، يلزم تحديد سجلاتها وأخذ نسخة احتياطية قبل إجراء تنظيف منفصل. بيانات الاختبارات محصورة في ملفات `backend/test/` وبيئة اختبار محمية.

تحتاج الميزات الجديدة إلى تحديث السيرفر والتطبيق معًا. إذا كانت نسخة Android القديمة موقّعة بمفتاح آخر، فلا يمكن تركيب APK الجديد فوقها كمجرد تحديث؛ استخدم مفتاح التوقيع القديم لإصدار تحديث يحافظ على التثبيت.

## التحقق

- اختبارات السيرفر: جميع فحوص المسارات الأساسية، و13 اختبارًا لدورة العمل والحسابات والصلاحيات والمخزون والعناوين وبدء التشغيل النظيف.
- اختبارات Android: التوقيع والمبالغ وتوجيه عناوين السيرفر.
- اختبارا صورة التوقيع على Android يحتاجان جهازًا أو محاكيًا للتشغيل.
